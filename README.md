# Vapor Browser

Vapor Browser is a Windows x86_64 fork of Zen Browser and Gecko. Round 1 is the
Foundation release: it keeps Zen's vertical tabs, workspaces, compact mode,
split view, and modern chrome while replacing the product branding and removing
Mozilla telemetry, sponsored content, and Mozilla service UI.

> The web, evaporated of nonsense.

## Build

See [BUILD.md](BUILD.md) for the reproducible Windows build instructions.

## Status

This repository intentionally implements only Round 1 of [SPEC.md](SPEC.md).
The Shield, Laser, Filter, routing, cookie automation, and all other later-round
features are not implemented yet.
